1. If there are no users added, add one using [Adding a User](/guide/add?target=_self) guide.
2. From the dropdown present Select the User to Configure & Click on the **Customize Post** button.
3. Use the buttons present in the message to update the embed message.
<mark>To toggle the notification embed use the **Hide / Show Embed** button.</mark>

4. To update the values of the embed Click on the **Change Embed** button & update the values in popup.
<mark>To set the embed back to defaults, click on the **Set Embed Defaults** button.</mark>

![embed2](/guide-assets/embed2.png?fullwidth=true)

5. To Toggle the **Watch Button** click on the **Hide / Show Button** button.
6. To Toggle the **Embed Timestamp** click on the **Hide / Show Timestamp** button.
7. To Toggle the **Currently Playing Game** in the embed click on the **Hide / Show Playing** button.
![embed3](/guide-assets/embed3.png?fullwidth=true)

8. To change the color in the notification embed select a **Color** from the dropdown menu.
![embed4](/guide-assets/embed4.png?fullwidth=true)
