1. If there are no users added, add one using [Adding a User](/guide/add?target=_self) guide.
2. Make sure in the notifications Channel the bot has the permissions to mention roles.
![role1](/guide-assets/role1.png?fullwidth=true)

3. From the dropdown present Select the User to Configure.
4. From the buttons present click on the **[Set / Change] Role** button.
5. Now from the dropdown **Select** a role to be pinged in the notifications.
![role2](/guide-assets/role2.png?fullwidth=true)

6. Now to update **{role.pingrole}** placeholder in the notifications message, use the [using placeholders](/guide/placeholders?target=_self) guide.
<mark>By default the **{role.pingrole}** placeholder is added at the start of the notification message.</mark>

![role3](/guide-assets/role3.png?fullwidth=true)
