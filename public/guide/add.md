1. Add Oreo to your Discord Server by going to [oreos.fun/invite](/invite).
2. Go to your server and from the slash commands menu use the **/settings** command.
3. Now use the buttons present to select a notifier to Add an User.
![add1](/guide-assets/add1.png?fullwidth=true)

4. From the dropdown present, select the **Add User** option & wait till the popup opens.
5. In the **Channel Url** section of the popup enter the Url of the Channel to Add.
6. After entering the **Channel Url** Click on the **Submit** button.
![add2](/guide-assets/add2.png?fullwidth=true)

7. **Done! 🎉** The user is added and now you can [customize](/guide/customize?target=_self) it using the guide.
![add3](/guide-assets/add3.png?fullwidth=true)
