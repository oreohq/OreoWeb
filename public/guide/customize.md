1. From the slash commands menu use the **/settings** command.
2. Select the notifier type & from the dropdown click on the **User** to customize.
<mark>If there are no users, add one using the [Adding a User](/guide/add?target=_self) guide.</mark>

![customize1](/guide-assets/customize1.png?fullwidth=true)

3. Now use the buttons present to customize the different settings.
4. To toggle the notifications use the **Enable / Disable** button.
5. Use the dropdown to select the **Content Types** for which the notifications should be sent.

![customize2](/guide-assets/customize2.png?fullwidth=true)

6. Use the **[Set / Change] Channel** button to Change the Channel for the notification to be sent.
<mark>If the Channel is an Announcement Channel, to publsh the posts make sure the **Publish Post** option is enabled.</mark>

![customize3](/guide-assets/customize3.png?fullwidth=true)
