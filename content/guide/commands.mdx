## Slash commands

### For server managers

| Command | What it does |
| --- | --- |
| **/settings** | Needs Manage Server. Opens the settings panel. Add `visibility:Public` to show it to everyone. See [Set up in Discord](/guide/quick-setup). |

### For everyone

| Command | What it does |
| --- | --- |
| **/notify** | Pick the creators you want to be pinged for. See [Let members opt in](/guide/notify). |
| **/help** | What Oreo does, with links to invite it, the dashboard, this guide and support. |

## Buttons on notifications

| Button | What it does |
| --- | --- |
| **Watch Stream**, **Watch Video**, **Watch Premiere**, **Watch Short** | Opens the post. Turn it on with the **Watch button** in [Style the embed](/guide/embeds). |
| **Watch the VOD**, **Visit on Twitch** | Replaces the watch button after a stream, if the post is updated. See [When the stream ends](/guide/stream-end). |
| 🔔 **Notify me** | Gives or removes the creator's ping roles. See [Let members opt in](/guide/notify). |
| 🧪 **Test notification** | Marks a test. Tests never ping anyone. |
